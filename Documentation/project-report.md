# AZ-104 Secure Multi-Tier Virtual Network Project

## Objective

Deploy a secure and monitored Azure infrastructure using best practices aligned with AZ-104 certification objectives.

## Environment

Resource Group:
RG-AZ104-MultiTier

Virtual Network:
VNET-1

Subnets:

- Management-Subnet
- Web-Subnet
- AzureBastionSubnet

## Components Implemented

### Networking

- Virtual Network
- Subnets
- NSG

### Compute

- Ubuntu Linux VM

### Security

- Azure Bastion
- NSG Inbound Rules

### Monitoring

- Azure Monitor
- Log Analytics Workspace

### Backup

- Recovery Services Vault
- VM Backup

## Results

Successfully deployed and validated secure access, monitoring, and backup capabilities within Azure.

## Cleanup

All resources were removed after testing to avoid additional Azure costs.
